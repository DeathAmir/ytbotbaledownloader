برای تبدیل این کد به یک کد C++ استاندارد تر، می‌توانیم به چند نکته توجه کنیم:

1. **استفاده از `std::` برای نام‌های فضاهای نام**: در C++ استاندارد، برای استفاده از توابع و کلاس‌های فضاهای نام مانند `std::cin` و `std::cout`، باید `std::` را قبل از آن‌ها قرار دهیم.

2. **استفاده از `using namespace std;` در بالای کد**: این روش می‌تواند کد را کوتاه‌تر کند، اما برای کدهای بزرگ و پروژه‌های معتبر، استفاده از `std::` برای نام‌های فضاهای نام پیشنهاد می‌شود.

3. **استفاده از `const` برای ثابت‌ها**: اگر مقادیر ثابتی داریم که در طول برنامه تغییر نمی‌کنند، می‌توانیم آن‌ها را با کلمه کلیدی `const` تعریف کنیم.

4. **استفاده از `auto` برای متغیرهای محلی**: اگر نوع داده متغیری مشخص نیست، می‌توانیم از کلمه کلیدی `auto` برای تعیین نوع داده آن استفاده کنیم.

5. **استفاده از `return 0;` در آخر `main`**: این کد برای نشان دادن اینکه برنامه بدون خطا به پایان رسیده است.

### نسخه استاندارد تر کد:

```cpp
#include <iostream>
#include <cmath>  // برای استفاده از توابع ریاضی مانند sqrt

int main() {
    using namespace std;  // استفاده از فضای نام std

    // تعریف متغیرهایی برای ذخیره مقادیر
    int a, b, c;
    double discriminant, root1, root2;

    // پرسیدن ورودی از کاربر
    cout << "لطفاً مقدار a را وارد کنید: ";
    cin >> a;
    cout << "لطفاً مقدار b را وارد کنید: ";
    cin >> b;
    cout << "لطفاً مقدار c را وارد کنید: ";
    cin >> c;

    // محاسبه دترمینان
    discriminant = b * b - 4 * a * c;

    // بررسی مقدار دترمینان برای تعیین ریشه‌ها
    if (discriminant > 0) {
        // دو ریشه متمایز
        root1 = (-b + sqrt(discriminant)) / (2 * a);
        root2 = (-b - sqrt(discriminant)) / (2 * a);
        cout << "ریشه‌های متمایز معادله هستند: " << root1 << " و " << root2 << endl;
    } else if (discriminant == 0) {
        // دو ریشه مساوی
        root1 = -b / (2 * a);
        cout << "ریشه‌های مساوی معادله هستند: " << root1 << endl;
    } else {
        // ریشه‌های مختلط
        cout << "ریشه‌های مختلط هستند." << endl;
    }

    return 0;  // نشان دادن اینکه برنامه به پایان رسیده است
}
```

### توضیحات کد:
1. **استفاده از `std::`**: برای نام‌های فضاهای نام مانند `cout` و `cin`.
2. **استفاده از `using namespace std;`**: برای کوتاه کردن کد.
3. **استفاده از `auto`**: در اینجا نیازی به `auto` نیست، اما می‌توانیم آن را برای متغیرهای محلی استفاده کنیم.
4. **استفاده از `return 0;`**: در آخر `main` برای نشان دادن اینکه برنامه به پایان رسیده است.

این نسخه کد به شکل استاندارد تر و قابلیت خواندن بیشتری دارد.
